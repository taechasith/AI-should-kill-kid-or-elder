# Kairokrisis v2

Kairokrisis (“judgment at the critical moment”) is a prospectively versioned research programme that tests whether semantic decision validity, interface-format reliability, and downstream physical safety diverge in safety-critical multimodal AI evaluation.

The earlier GeoSAVE Phase 4–9 pilot remains frozen, historically accurate, and reproducible. It is a feasibility foundation, not a dataset to be silently relabelled or modified by Kairokrisis v2. The current legal layer remains `NOT_ESTIMABLE`; map/road constraint compliance is not legal compliance.

See `docs/kairokrisis/KAIROKRISIS_V2_NMI_METHODOLOGY_GUIDE.md` for the controlling protocol and `docs/kairokrisis/KAIROKRISIS_V2_PREREGISTRATION.md` for the prospective v2 specification.

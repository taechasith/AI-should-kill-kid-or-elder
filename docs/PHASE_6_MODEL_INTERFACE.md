# Phase 6 model-interface gate

This gate freezes an offline-only model registry, neutral versioned prompt contract, strict JSON parser, one deterministic fence-only repair attempt, and append-only raw-response storage. No model is enabled, invoked, benchmarked, or compared. Provider/API use requires a separately authorized model list, scale, and cost estimate.

The parser never selects an action on behalf of a failed response, never treats unknown law as permission, and retains parse failure explicitly. Prompts must not reveal an expected action or encode demographic valuation.

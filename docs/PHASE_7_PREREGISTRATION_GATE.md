# Phase 7 preregistration gate

The manifest contract and analysis-plan draft exist, but the Phase 7 template is
deliberately `UNFROZEN` and has no rows. The frozen Phase 5 input is
`phase5-legal-snapshot-v1`; its unresolved records remain `NOT_DETERMINED` and
must not be promoted to permissions. Phase 6 has only an offline candidate
panel and blocked dry-run, not a successful provider pilot. This gate cannot
authorize law collection, provider calls, local model execution, or benchmark
analysis. A later freeze must use a new versioned manifest and preserve all
planned, failed, excluded, parsed, and `not_applicable` records.

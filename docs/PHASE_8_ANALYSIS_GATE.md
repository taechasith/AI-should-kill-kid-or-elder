# Phase 8 counterfactual and analysis gate

This gate provides only analysis contracts: counterfactual-pair representation, parse-failure exclusion accounting, flip-rate calculation, and deterministic Benjamini-Hochberg adjusted q-values. It contains no model output, legal conclusion, counterfactual execution, inference, or result claim.

When Phase 7 benchmark data are validly available, each analysis must retain paired run IDs, manipulation type, parse/exclusion status, raw counts, effect sizes, uncertainty intervals where applicable, and FDR-adjusted results. Findings are behavioral associations and explanation-faithfulness proxies, never evidence of reasoning, psychological traits, causality, legal advice, or safety certification.

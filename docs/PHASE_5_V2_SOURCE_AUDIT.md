# Phase 5 v2 source audit

The primary-source search log begins empty by design. This distinguishes
`NOT_STARTED` from `NO_PRIMARY_SOURCE_FOUND`. Each final evidence record must
record official URL, issuing authority, provision locator, retrieval date,
effective-date state, source language, translation method, applicability,
exceptions, and review state.

Secondary sources may aid discovery or translation cross-checking but cannot be
the sole authority for a final action-level status.

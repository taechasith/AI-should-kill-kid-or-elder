# Phase 5 deterministic GeoSAVE baseline

Phase 5 begins with a deterministic candidate-action baseline only. It accepts explicit physical evidence and explicit legal-status inputs; it does not collect, infer, or invent law. The stages are feasibility, catastrophic physical risk, legal status, safety-law conflict, and uncertainty/controllability tie-breaking.

Unknown law is never treated as lawful. A physically safer but prohibited action remains labelled as a safety-law conflict rather than being relabelled legal. This baseline contains no demographic value weighting and no foundation-model component.

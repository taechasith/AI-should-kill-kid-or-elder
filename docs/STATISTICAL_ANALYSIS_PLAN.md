# Statistical analysis plan — Phase 7 draft

**Status:** draft only; not an experiment freeze or a benchmark result.

The eventual Phase 7 manifest will predefine reviewed legal snapshot, jurisdictions, model revisions, prompts, C0/C1/C2/C4 conditions, exclusions, paired decision units, and failure handling before any model execution. Each model decision must join exactly one immutable Phase 4 physical run and one explicit legal decision or `NOT_DETERMINED` status.

Primary descriptive outcomes will be physical-risk category, legal status, safety-law relation, parse/failure counts, and unknown-law rate. Any later inferential analysis will report effect sizes, confidence intervals, hierarchical structure where justified, missing/failure handling, and FDR control for planned multiple comparisons. No causal, psychological, legal-advice, or safety-certification claim is prespecified.

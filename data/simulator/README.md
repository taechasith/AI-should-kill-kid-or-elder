# Simulator Data Boundary

No CARLA or other simulator output exists in this repository yet.

`physical_outcomes/` is reserved for output generated by an executable,
version-pinned local simulation run. It must never contain manually estimated,
hand-authored, or model-generated physical outcomes.

The only physical-outcome JSON used before simulator availability is a test
fixture under `tests/fixtures/`. It validates the schema and is not research
data, not a simulation result, and not eligible for analysis.
